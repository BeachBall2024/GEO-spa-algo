# GEO Chatty Maps Zurich

This repo is our GEO final project for recreating the idea of **Chatty Maps** in
Zurich: use geotagged Flickr photos, read the tags as possible sound clues,
join them to nearby streets, and map each street segment by its dominant sound
category.

The repo was cleaned up for final submission, so it should now be much easier
to understand.

## Repo Structure

- `submission_final_self_contained.ipynb`  
  This is the final notebook to run/submit. It follows the same structure as
  the original group notebook, but the helper classes and functions are defined
  directly at the top of the notebook. This means the final notebook does not
  need `geo_proxy` imports and should be easier to run in Google Colab.

- `submission.ipynb`  
  The original group notebook, kept for transparency and to preserve the work
  process/structure.

- `data/`  
  Small CSV files and final intermediate data. The key files are
  `data/zurich_street_segments.csv`, `data/zurich_sounds.csv`, and
  `data/pipeline_results.csv`.

- `plots/`  
  Final output figures generated by the notebook: the sound maps, category
  totals, matched-point coverage, and segment length distribution.

- `geo_proxy/`  
  Original helper package from the working process. It is kept for transparency,
  but the final self-contained notebook does not depend on it.

- `requirements.txt`  
  Minimal Python packages for the plots. `contextily` is only needed for the
  basemap plot; if it is missing, the notebook can still generate the other
  plots.

## Data We Need

The big Flickr dataset is **not** in GitHub because it is too large. For the
full run, copy it from the shared folder to:

```text
Flickr_CH_ALL/Flickr_CH_ALL.csv
```

The file uses `;;` as separator. If this file is not available, the final
notebook can fall back to the smaller sample file:

```text
data/zurich_sounds.csv
```

For the street network/results we need:

```text
data/zurich_street_segments.csv
```

The noise file `data/zurich_noise.csv` is only for exploratory future work. We
are not using it as a main result because the source/provenance is not clear
enough for a strong final claim.
